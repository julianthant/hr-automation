# JSON Schemas

Generated by `npm run schemas:export` from workflow Zod input schemas listed in
`src/scripts/codegen/export-schemas.ts`.

Wire these into VSCode's `yaml.schemas` setting (in `.vscode/settings.json`) to get
autocomplete + validation while editing batch YAML files, e.g.:

```jsonc
{
  "yaml.schemas": {
    "./generated/schemas/emergency-contact.schema.json": "src/workflows/emergency-contact/**/batch*.yaml"
  }
}
```

The `*.schema.json` files here are gitignored. Re-run `npm run schemas:export`
after any workflow schema change, or after adding a new workflow schema entry to
the script's `SCHEMA_REGISTRY`.
