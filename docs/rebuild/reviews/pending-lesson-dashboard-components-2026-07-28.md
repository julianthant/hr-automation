do not soften that parse, pin the fixture format instead). Once, a Radix `Tooltip` rendered with no `TooltipProvider` — the throw was swallowed by the error boundary, so the symptom was not an error but a BLANK PAGE, which a component test would never have rendered far enough to see. Once, a `Popover` that teleported the toast viewport across the window on every open (`5f4a5dba` — the modal-presence registry treated a popover like a dialog, so every row ⓘ, every menu and the date picker shoved the toasts bottom-right → bottom-left; a popover now registers as a `layer`: cards go inert, NOTHING moves). **Booting and driving the real built bundle is not optional verification — it is the only tier that catches this whole class.** **GOTCHA 2 — a "failed: stalled" agent notification was WRONG; the agent was still writing.** Two agents ended up editing the same tree concurrently. No work was lost — but only because each staged explicit paths and their edits happened to be file-disjoint. Verify an agent is actually dead (its process, not its notification) before relaunching over it. **GOTCHA 3 — a `git checkout` used to build a "before" comparison screenshot discarded four uncommitted files.** Never `checkout` / `stash` / `reset` a shared working tree to get a comparison state — build the comparison from a worktree or from the archived screenshots. **GOTCHA 4 — port `N+1` is not free:** the dashboard's phone-capture sidecar binds `port + 1`, so two agents on consecutive ports collide in the middle even when their own ports are clear — space preview ports by 2. **GOTCHA 5 — a worktree has no `.env`**, so `dashboard:prod` dies immediately there; copy or link it before booting a preview from a worktree. **GOTCHA 6 — the duplication was SYSTEMIC, not incidental, and grep proves it before a redesign does:** the status word was restated in **25** fixture outcome strings directly beside the pill already showing it; one surface said `Waiting on you` **four times**; and a one-branch `.replace("Waiting on you — ", "")` had papered over exactly **1 of 9** restatement sites — a display-layer patch over an authoring-layer defect, which is why the fix was deleting the restatements at the source, not widening the replace. Same class: **21 fixtures carried step durations exceeding their own stated total** — now pinned by `tests/unit/dashboard/rebuild-demo-duration-reconciles.test.ts`, because a fixture that contradicts itself will eventually be believed by some surface. **GOTCHA 7 — a design-system fix half-lands by default.** The tokens/primitives unification migrated `Chip`, `Well` and the row footer correctly — while **nine hand-rolled chips and four structural twins** of existing primitives survived untouched in the same tree, and `CardFooter` looked correct only because its single use happened to sit in a one-column stack where the sibling-alignment defect cannot manifest. A primitive migration is not done when the primitive exists; it is done when a sweep proves no surface still hand-rolls the shape (the wave-16 single-sourcing tests exist to hold exactly this).
